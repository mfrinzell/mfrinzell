### 📌 Featured project — [`realtime-ai-governance`](https://github.com/mfrinzell/realtime-ai-governance)
*Metal to cloud through real-time AI orchestration.*

A real-time pipeline that ingests a public privacy/regulatory feed (FTC, EUR-Lex), routes each item through a multi-agent **classify → assess → register** flow, and emits a versioned governance register that a daily job keeps current — a diffable, auditable record of what surfaced and when.

- Deterministic, zero-API-key core — reproducible in CI, runs anywhere
- Optional, explicitly gated LLM classifier
- Automated tests, lint, and CI; a scheduled job that commits an auditable artifact

A working demonstration of the pattern, built to extend — more sources, alerting, a dashboard — rather than claimed as a production system.
